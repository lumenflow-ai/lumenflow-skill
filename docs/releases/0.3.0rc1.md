# Lumenflow Skill 0.3.0rc1

Release candidate for Codex and Claude Code. This document describes the
candidate; it does not announce a published GitHub release or a stable version.

License: [MIT](../../LICENSE). Copyright (c) 2026 Lumenflow.

## Capabilities

- Project and empty-episode creation, asset imports and batch scene-prompt edits.
- Canvas reads, edits, media uploads, model discovery and generation quotes.
- Authorized business-text review, progress and failure queries, and downloads.
- Explicitly authorized generation workflows, including standalone Seedance 2.5
  jobs with local references. Generating content can consume credits.

## Requirements and installation

Python 3.11 or later is required. The runtime uses the Python standard library.
Follow the [installation instructions](../../README.md#install), then check the
installed script with `--version` and `--help`. Expected version: `0.3.0rc1`.

The installation command follows the default branch. No version tag is implied
by this document. Existing installations must be explicitly updated; installing
this Skill does not migrate credentials or add account permissions.

## Authorization and safety

- Configure `LUMENFLOW_API_KEY` privately on your own device, outside AI chats,
  source files and logs. Use only the scopes and resources needed for the task.
- The client accepts the official public API host and rejects redirects and
  unsupported hosts. It does not fall back to internal or Web APIs.
- The service enforces resource ownership and scope checks. A modified client
  does not grant access to another account's data.
- Retain the same idempotency key and inputs when recovering an uncertain write.
  Do not generate a new key to bypass a conflict or retry an unknown outcome.
- Model-selected generation requires a current quote and explicit confirmation.
  Installation, a quote, or a read request is not permission to generate.
- Report security concerns privately using [SECURITY.md](../../SECURITY.md).

## Validation and limitations

The release checks cover Python 3.11–3.14, offline contract and security tests,
source/history secret-pattern scanning, and source archive handling. Client
installation, non-billable reads and writes, uploads, quotes, retry recovery and
cross-account rejection have been exercised separately with test resources.

Paid generation and parsing, model-driven conversation/tool selection, and every
enterprise role or media codec combination have not been fully acceptance-tested.
Do not interpret this candidate as a guarantee of those flows. Anonymous
installation is a separate publication gate; authenticated installation alone
does not establish it.

This distribution contains the client, reference documents and offline tests.
It does not include server credentials, service configuration or internal
acceptance records. Secret scanners are defense in depth, not proof that a
repository can never contain a secret.
